# Autofill Kuesioner SIAM UB
 
Script untuk mengisi kuesioner dosen di SIAM UB secara otomatis lewat console browser.
 
## Cara Pakai
 
1. Buka halaman kuesioner di `siam.ub.ac.id/mahasiswa/kuisioner`
2. Tekan `F12` → tab **Console**
3. Copy isi `script.txt` → paste → **Enter**
## Konfigurasi
 
```js
const ANSWER_INDEX = 4; // 0 = Sangat Tidak Baik, 4 = Sangat Baik
const SARAN = "Dosen mengajar dengan baik";
```
